Feature Comparison
Feature Option A — 4-Tab Option B — 3-Tab Option C — Swipe
See entire trip at once ✓ Dedicated Trip tab ✓ Calendar tab, collapsed days ~ All Days tab (compressed view)
Daily hourly view ✓ Dedicated Day tab ✓ Expand any day inline ✓ Primary default screen
Backlog ✓ Dedicated tab, full screen ✓ Dedicated tab, full screen ~ Bottom sheet (overlay)
Check-in / Checkout ✓ Stay card on Trip tab + chip on day ✓ Stay card on Calendar tab ✓ Alert strip on check-in day
Suggestions (your list) ✓ Dedicated Nearby tab ✓ Discover tab, by day ✓ Suggestion pill in day view
Suggestions (beyond list) ✓ "New" badge on Nearby tab ✓ "New" badge on Discover tab ✓ "Not in list" tab in suggestions
Navigation clarity ✓✓ Most explicit, 4 clear tabs ✓ Clean, but expand is less obvious ~ Gesture-heavy, less discoverable
Screen real estate ~ Split between 4 tabs ✓ Day view maximized in calendar ✓✓ Most content space per screen
Easiest for quick use mid-trip ~ 1 tap to any screen ~ 1–2 taps to day detail ✓✓ Day view is instant, swipe between days
Best for planning ahead (at home) ✓✓ Trip overview + backlog side by side ✓✓ Expand-in-place is great for planning ~ One day at a time

Recommendation: Option A or B for pre-trip planning · Option C for mid-trip day-of use
These can be combined: Option A's structure + Option C's swipe gesture between days
