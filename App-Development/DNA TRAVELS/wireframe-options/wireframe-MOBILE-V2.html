Section 1 — Your List
Places from your Google Maps save that are not yet scheduled on this day, sorted by distance from that day's planned area.

Places already on this day show ✓ On day.
Section 2 — Discover New ✨
Uses Google Places API to pull real nearby places that are not in your Google Maps list at all. Filtered by: proximity to that day's neighborhood, open hours, and rating.

Requires API key setup (see below).
What "+ Add" does
Adds the place to that day's unscheduled block list (like adding from the backlog). You can then drag it to a time slot in the Day tab.

Places added from "Discover New" also get saved to your app's local catalog so they show up in the backlog.
6. Google Places API — setup required before "Discover New" works
How to get your API key (it's free to start):
  1. Go to console.cloud.google.com
  2. Create a new project (or pick an existing one) — name it "DNA TRAVELS"
  3. Click APIs & Services → Library and enable "Places API (New)"
  4. Click APIs & Services → Credentials → Create Credentials → API key
  5. Copy the key — paste it into the app's Plan form (we'll add an "API key" field)
  6. Optional but recommended: restrict the key to your device's IP and to the Places API only

Cost: Google gives $200/month free credit. Each "Nearby Search" call costs ~$0.032. For personal trip planning use, this will cost you literally $0.

What Claude can do: Once you have the key, I'll wire up the API call in app.js — searching for places within 0.5 mi of that day's neighborhood, filtered by category (restaurant/coffee/museum/park), sorted by rating.
